### Resumo do projeto, território e execução
O SQEducaPlay nasceu para apoiar a aprendizagem de crianças do 2º ao 5º ano do Ensino Fundamental I, com foco em atividades gamificadas de Português e Matemática alinhadas à BNCC.

O território de referência do projeto é o município de Saquarema (RJ), considerando o contexto de escolas da rede local e a necessidade de uma solução acessível para uso pedagógico em sala e em atividades de reforço.

Nesta fase, a aplicação opera principalmente com armazenamento local no dispositivo (SQLite no app e limitações no Web). Isso significa que o projeto ainda está em modelo de execução local, sem backend central para produção institucional em larga escala.

Próximos passos de evolução:
- Publicar backend seguro para persistência centralizada.
- Disponibilizar portal público com informações institucionais e transparência.
- Expandir o uso para múltiplas escolas com gestão unificada de dados.

## �📊 Banco de Dados SQLite

O app agora possui **persistência de dados local** usando SQLite! Todos os progressos, pontuações e histórico de partidas são salvos automaticamente.

**Funcionalidades:**
- ✅ Criação automática de usuários no login
- ✅ Salvamento automático de partidas ao finalizar quiz
- ✅ Ranking real com top 20 alunos (geral + por matéria)
- ✅ Estatísticas pessoais: histórico, taxa de acerto, progresso por matéria
- ✅ Funciona 100% offline (sem internet)

📖 **[Leia a documentação completa do banco de dados](BANCO_DADOS_README.md)**

### Como testar:
1. Faça login com qualquer usuário (ex: aluno1 / 123)
2. Jogue um quiz até o final
3. Clique em "📊 Estatísticas" no menu superior
4. Clique em "🏆 Ranking" para ver o ranking
5. Jogue mais quizzes para subir no ranking!
